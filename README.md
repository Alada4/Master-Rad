# Master rad - Prateći materijali

Ovaj repozitorijum sadrži kompletnu dokumentaciju, programski kod i prateće fajlove za master rad.

## Sadržaj repozitorijuma
- **Dokumentacija i prezentacija:** PDF master rada, PowerPoint prezentacija (`Master.pptx`)
- **PLC i HMI projekti:** Fatek PLC program (`OdbranaMasterRada.pdw` / `.emtp`)
- **EPLAN i šeme:** EPLAN dokumentacija i vizuelni prilozi (`.png`, `.jpeg`)
- **Demo video:** Video demonstracija rada sistema (`Demo projekat.mp4`)
